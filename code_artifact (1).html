رابط صفحة الأدمن (تحكم كامل)

يفتح النظام في وضع التحكم الكامل لإضافة وتعديل الأنشطة والنقاط.

كيف ترفع هذا النظام على الإنترنت مجاناً (بدون أي تكلفة) في دقيقة واحدة؟

1. موقع Netlify Drop (الأسرع - بدون برمجة)
  1. قم بتحميل هذا الملف بصيغة index.html على جهازك.
  2. افتح موقع app.netlify.com/drop مجاناً.
  3. اسحب الملف وأفلته داخل الصفحة، وسيعطيك فوراً رابطاً مجانياً دائماً يعمل على الموبايل والكمبيوتر!
2. موقع GitHub Pages / Vercel (مجاني للأبد)
  1. أنشئ مستودعاً (Repository) مجانياً على GitHub.com.
  2. ارفع الملف باسم index.html ثم فعّل GitHub Pages من الإعدادات.
  3. أرسل للإدارة الرابط مع إضافة ?mode=view في نهايته.
نسخ احتياطي للبيانات (JSON): احفظ نسخة من كافة الأنشطة أو استرجعها في أي وقت.
