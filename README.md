# 📊 نظام لوحة كانبان الموزونة بالنقاط ومتتبع الجدول الزمني
## Weighted Kanban & Timeline Roadmap Fullstack System

تطبيق متكامل واحترافي لإدارة المشاريع بنظام **النقاط الموزونة (Weighted Story Points)**، وحدود العمل الجاري **(WIP Limits)**، ومتتبع الجدول الزمني **(Gantt Roadmap)**، ولوحة تقارير الإدارة التنفيذية **(Executive Summary)**.

تم بناء التطبيق بهندسة برمجية حديثة تشمل:
- **قاعدة البيانات (Database)**: قاعدة بيانات علائقية كاملة **SQLite** تدعم الـ ACID Transactions والمفاتيح الأجنبية والفهارس وسكربتات التهيئة والبذور.
- **الباك إند (Backend)**: خادم REST API مبني بواسطة **Node.js & Express** مع طبقات Models و Controllers و Services وحماية كاملة بصلاحيات الأدمن برمز مرور (PIN) وميدلوير التحقق.
- **الفرونت إند (Frontend)**: واجهة مستخدم تفاعلية متطورة مبنية بـ **React 18 + Vite + Tailwind CSS + Lucide Icons** مع دعم كامل وثنائي اللغة (العربية RTL والإنجليزية LTR)، وسحب وإفلات تفاعلي (Drag & Drop)، وتحديثات حية.

## 🗄️ تصميم قاعدة البيانات (Database Schema)

تم إنشاء قاعدة بيانات علائقية كاملة باستخدام **SQLite** عبر المحرك المدمج في Node.js، تتضمن الجداول التالية:

### 1. جدول المشاريع (`projects`)
| العمود | النوع | الوصف |
|---|---|---|
| `id` | TEXT PRIMARY KEY | معرف المشروع (`main-project`) |
| `title_ar` | TEXT | اسم المشروع بالعربية |
| `title_en` | TEXT | اسم المشروع بالإنجليزية |
| `wip_limit` | INTEGER | الحد الأقصى لنقاط قيد التنفيذ (افتراضي: 15) |
| `admin_pin` | TEXT | رمز حماية الأدمن (افتراضي: `1234`) |
| `created_at` | DATETIME | تاريخ الإنشاء |
| `updated_at` | DATETIME | تاريخ آخر تحديث |

### 2. جدول الفئات والمراحل (`categories`)
| العمود | النوع | الوصف |
|---|---|---|
| `id` | TEXT PRIMARY KEY | الرمز (`infra`, `database`, `security`, `frontend`, `management`, `qa`) |
| `name_ar` | TEXT | الاسم بالعربية |
| `name_en` | TEXT | الاسم بالإنجليزية |
| `color_class` | TEXT | كلاسات Tailwind الخاصة بالألوان |
| `icon` | TEXT | اسم الأيقونة |
| `display_order` | INTEGER | ترتيب العرض |

### 3. جدول الأنشطة والمهام (`tasks`)
| العمود | النوع | الوصف |
|---|---|---|
| `id` | TEXT PRIMARY KEY | المعرف الفريد للنشاط |
| `project_id` | TEXT | معرف المشروع (مفتاح أجنبي) |
| `title_ar` | TEXT | عنوان النشاط بالعربية (إلزامي) |
| `title_en` | TEXT | عنوان النشاط بالإنجليزية |
| `category_id` | TEXT | تصنيف المرحلة (مفتاح أجنبي) |
| `points` | INTEGER | وزن الجهد بالنقاط (1, 2, 3, 5, 8, 13) |
| `start_date` | DATE | تاريخ بدء النشاط |
| `due_date` | DATE | تاريخ الاستحقاق والموعد النهائي |
| `assignee_ar` | TEXT | المسؤول بالعربية |
| `assignee_en` | TEXT | المسؤول بالإنجليزية |
| `status` | TEXT | الحالة (`backlog`, `inprogress`, `review`, `done`) |
| `notes_ar` | TEXT | ملاحظات وتفاصيل بالعربية |
| `notes_en` | TEXT | ملاحظات وتفاصيل بالإنجليزية |
| `position` | INTEGER | الترتيب داخل العمود |

### 4. جدول سجل النشاطات والتدقيق (`activity_logs`)
| العمود | النوع | الوصف |
|---|---|---|
| `id` | INTEGER PRIMARY KEY | ترقيم تلقائي |
| `task_id` | TEXT | معرف النشاط المرتبط |
| `action` | TEXT | نوع الإجراء (`created`, `updated`, `status_changed`, `deleted`, `reset`) |
| `details` | TEXT | تفاصيل التغيير بتنسيق JSON |
| `created_at` | DATETIME | التوقيت الزمني |

## ⚡ واجهات البرمجة الخلفية (REST API Endpoints)

| المسار | الطريقة | الصلاحية | الوصف |
|---|---|---|---|
| `/api/health` | GET | عام | فحص سلامة الخادم |
| `/api/project` | GET | عام | جلب إعدادات واسم المشروع |
| `/api/project` | PUT | أدمن (`x-admin-pin`) | تعديل اسم المشروع، حد الـ WIP، أو الـ PIN |
| `/api/auth/verify` | POST | عام | التحقق من صحة رمز الأدمن |
| `/api/categories` | GET | عام | جلب فئات ومراحل المشروع |
| `/api/tasks` | GET | عام | جلب الأنشطة مع دعم الفلترة والبحث |
| `/api/tasks` | POST | أدمن (`x-admin-pin`) | إنشاء نشاط جديد مع التحقق من صحة التواريخ |
| `/api/tasks/:id` | PUT | أدمن (`x-admin-pin`) | تعديل بيانات النشاط بالكامل |
| `/api/tasks/:id/status` | PATCH | أدمن (`x-admin-pin`) | نقل النشاط بين الأعمدة (سحب وإفلات) |
| `/api/tasks/:id` | DELETE | أدمن (`x-admin-pin`) | حذف النشاط |
| `/api/metrics` | GET | عام | جلب ملخص الـ KPIs ونسب الإنجاز الموزونة |
| `/api/export/csv` | GET | عام | تصدير الأنشطة إلى Excel/CSV مع دعم العربية (BOM) |
| `/api/backup/export` | GET | عام | تصدير نسخة احتياطية كاملة JSON |
| `/api/backup/import` | POST | أدمن (`x-admin-pin`) | استيراد واسترجاع نسخة احتياطية JSON |
| `/api/reset` | POST | أدمن (`x-admin-pin`) | استعادة الأنشطة الثمانية الافتراضية |

## 🚀 طريقة التشغيل (How to Run)

### 1. التشغيل الفوري بنقرة واحدة (على ويندوز)
قم بالنقر المزدوج على ملف:
```
run.bat
```
سيقوم تلقائياً بتثبيت الحزم وبناء الواجهة وتشغيل الخادم وفتح المتصفح على:
`http://localhost:5000`

---

### 2. التشغيل عبر الأوامر (Terminal)

#### لتشغيل بيئة التطوير (Hot-Reload لكلا الطرفين):
```bash
npm run dev
```
- واجهة المستخدم: `http://localhost:3000`
- الخادم الخلفي: `http://localhost:5000`

#### لتشغيل بيئة الإنتاج على منفذ واحد:
```bash
npm run build
npm start
```
يفتح التطبيق بالكامل على المنفذ `http://localhost:5000` حيث يقوم خادم Express بتقديم واجهة React وواجهات الـ REST API معاً.

#### لإعادة تهيئة وبذر قاعدة البيانات:
```bash
npm run db:init
```

## 🔒 نظام المستخدمين والصلاحيات (User Admin & Roles)

يحتوي النظام الآن على **نظام إدارة مستخدمين ومدراء كامل (User Admin)** مع تشفير كلمات المرور وحفظها في قاعدة البيانات:

### 👤 الحساب الافتراضي لمدير النظام (Default Superadmin):
* **اسم المستخدم (Username):** `admin`
* **كلمة المرور (Password):** `admin123`
* **الاسم الكامل:** مدير النظام الرئيسي
* **رمز PIN السريع:** `1234`

### 🛠️ ما يمكنك فعله من نافذة "إدارة المستخدمين":
1. **إنشاء مستخدم / مدير جديد**: إدخال اسم المستخدم، الاسم الكامل، كلمة المرور، وتحديد الصلاحية:
   - **مدير نظام (Admin)**: يمتلك كامل صلاحيات الإضافة، التعديل، الحذف، وسحب الأنشطة، وتعديل إعدادات المشروع.
   - **مشاهد (Viewer)**: عرض تنفيذي للقراءة فقط وتصدير التقارير دون إمكانية التعديل أو الحذف.
2. **تعديل بيانات المستخدم**: تغيير الاسم، تعديل الصلاحية، أو إعادة تعيين كلمة المرور.
3. **حذف المستخدمين**: مع حماية ذكية تمنع حذف آخر مدير نظام حتى لا يُقفل الحساب.

## 🎨 إدارة التصنيفات ومراحل العمل (Categories CRUD)
يمكنك من زر **"إدارة الفئات"** في الترويسة:
* إضافة تصنيفات ومراحل عمل جديدة للمشروع (مثل: `التصميم وتجربة المستخدم`, `التسويق`, `المشتريات`).
* اختيار نسق الألوان الخاص بكل مرحلة.
* تعديل أسماء الفئات بالعربية والإنجليزية.
* حذف الفئات غير المستخدمة.

## ⚡ العمليات المتاحة في التطبيق (Full CRUD)
* **الأنشطة والمهام (Tasks)**: إضافة نشاط جديد، تعديل، حذف، نقل الحالات بالسحب والإفلات.
* **المستخدمين (Users)**: إضافة مستخدمين ومدراء، تعديل، حذف، تغيير كلمة المرور.
* **المراحل والتصنيفات (Categories)**: إضافة فئات عمل جديدة، تعديل، حذف.
* **إعدادات المشروع (Settings)**: تعديل اسم المشروع عربي وإنجليزي، وتعديل الحد الأقصى للنقاط (WIP Limit).
* **النسخ الاحتياطي (Backup)**: تصدير واستيراد ملفات JSON وتصدير Excel/CSV.
